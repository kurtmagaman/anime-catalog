АНИМЕ-КАТАЛОГ — версия с catalog.json

На GitHub замените index.html и добавьте catalog.json в корень репозитория.
Папку assets менять не нужно.

Дальше для добавления аниме достаточно:
1. загрузить новый PNG в assets;
2. добавить объект в catalog.json.

Важно: URL должен вести на первое сообщение соответствующей темы Telegram.
